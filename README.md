# CRUD de Pacientes - Laravel

Este es un proyecto educativo desarrollado con el framework **Laravel** que implementa un sistema básico de registro y administración de pacientes. El objetivo principal es demostrar el uso de operaciones CRUD (Create, Read, Update, Delete) integrando las mejores prácticas del framework.

## 🚀 Funcionalidades

- **Registro de Pacientes:** Formulario para dar de alta nuevos pacientes en el sistema.
- **Listado Dinámico:** Visualización de todos los pacientes registrados con opciones de gestión.
- **Actualización de Datos:** Edición de información existente de manera sencilla.
- **Eliminación Segura:** Opción para remover registros de la base de datos.
- **Vistas con Blade:** Uso del motor de plantillas Blade para una interfaz limpia y modular.

## 📂 Estructura del Proyecto

- `app/Http/Controllers`: Contiene la lógica para gestionar las rutas y los datos de los pacientes.
- `app/Models`: Definición del modelo de datos para la interacción con la base de datos mediante Eloquent.
- `resources/views`: Plantillas de la interfaz de usuario desarrolladas con Blade.
- `database/migrations`: Archivos para la creación automática de las tablas necesarias.
- `routes/web.php`: Definición de las rutas de la aplicación.

## 🛠️ Tecnologías

- **Framework:** Laravel 8.x / 9.x
- **Backend:** PHP 8.1+
- **Base de Datos:** MySQL
- **Frontend:** HTML, Bootstrap (o CSS personalizado), Blade
